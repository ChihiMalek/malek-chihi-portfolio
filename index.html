PROJECT / 04 — ROBOTICS & CONTROL SYSTEMS

RRR Robotic Manipulator — Kinematics & Control

Modelling and control of a 3-DOF RRR robotic manipulator via MATLAB/Simulink. Forward & inverse kinematics with trajectory optimization validated before physical implementation.

Modélisation et contrôle d'un manipulateur robotique 3-DOF (RRR) via MATLAB/Simulink. Cinématique directe et inverse avec optimisation de trajectoires validée avant implémentation physique.

<0.8mm error 98% path follow <1ms solve time
MATLABSimulink KinematicsC/C++ Control Systems

Engineering Problem

Problème d'ingénierie

Designing precise control systems for robotic arms requires validated kinematic models before physical implementation to avoid actuator damage and guarantee positioning accuracy.

La conception de systèmes de contrôle précis pour bras robotique nécessite des modèles cinématiques validés avant implémentation physique pour éviter les dommages aux actionneurs et garantir la précision.

Implemented Solution

Solution implémentée

  • Forward kinematics: homogeneous transformation matrix (D-H)
  • Cinématique directe : matrice de transformation homogène (D-H)
  • Inverse kinematics: geometric method + joint control (Kp=3, Ki=0.5)
  • Cinématique inverse : méthode géométrique + contrôle articulaire (Kp=3, Ki=0.5)
  • Simulink simulation: circular trajectory 1.5m radius, 10s, ode4 solver
  • Simulation Simulink : trajectoire circulaire R=1.5m, 10s, solveur ode4
  • PID validation: closed-loop position control · singularity analysis
  • Validation PID : contrôle de position en boucle fermée · analyse des singularités
